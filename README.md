One line an older self would send back to his younger self — a warning about a trade he will regret for decades: the guitar sold for a car that barely lasts. An entry for make.fun's "One Line to Your Younger Self" bounty. The program validates the line (1–200 characters, a single line, no control characters) and writes it to `/output/entry.txt`, then reads it back and fails if the bytes differ.

The line:

> Don't sell the guitar to pay for the car — you'll drive the car for three years and miss the guitar for thirty.

## Run it

```sh
node main.ts
```

Node 22+ runs the TypeScript directly (type stripping). Set `MAKEFUN_OUTPUT_DIR` to write `entry.txt` somewhere other than `/output`.
